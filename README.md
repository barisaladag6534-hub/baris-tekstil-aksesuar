# Barış Tekstil Aksesuar — web sitesi

Statik, mobil uyumlu tanıtım sitesi. Herhangi bir ücretli yazılım ya da sunucu gerektirmez.

## Önizleme

`index.html` dosyasını tarayıcıda açın. Görsel, `assets/` klasöründedir (WebP).

## Yayınlamadan önce

`index.html` içindeki İletişim alanına gerçek e-posta adresinizi veya WhatsApp numaranızı ekleyin. Bu site statik olduğundan form verisi toplamaz.

## Ücretsiz yayınlama (GitHub Pages)

1. GitHub'da yeni ve **public** bir depo oluşturun.
2. Bu klasörün içindeki `index.html` ve `assets/` klasörünü deponun kök dizinine yükleyin.
3. Depoda **Settings → Pages** bölümünü açın.
4. **Deploy from a branch** seçin; `main` ve `/(root)` seçip kaydedin.
5. Yayınlanan adres aynı Pages bölümünde görünür. GitHub Free'de Pages için depo herkese açık olmalıdır.

Ayrıntılı yönergeler: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
